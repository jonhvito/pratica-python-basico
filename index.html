    nome = input()
idade = int(input())
nota = float(input())
print(nome, idade)

    input() devolve texto. Converta antes de calcular. Decimais usam ponto: 7.5.

    Condições

    if nota >= 7:
    print("aprovado")
elif nota >= 5:
    print("recuperacao")
else:
    print("reprovado")

    Dois-pontos e recuo de 4 espaços. = atribui; == compara igualdade; >= significa “maior ou igual”.

    Repetição

    for n in range(1, 6):
    print(n)

n = 1
while n <= 5:
    print(n)
    n += 1

    O final de range fica de fora. No while, lembre de atualizar a variável.

    Listas e acumuladores

    numeros = [4, 8, 2]
total = 0
for n in numeros:
    total += n

pares = []
pares.append(4)

    Índices começam em zero: numeros[0]. len(numeros) dá o tamanho.

    Funções

    def dobro(numero):
    return numero * 2

resultado = dobro(5)
print(resultado)

    return devolve o valor e encerra a função. print só escreve na saída.
